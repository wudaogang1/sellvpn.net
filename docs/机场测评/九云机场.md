## 备用包的有效期和优惠资格

商店标注 365 天的两档分别是 **¥19.90/500GB** 和 **¥29.90/1000GB**，额度在整个有效期内共用。当时的账户对这两档均未验券成功，其中 500GB 查看的是已有订阅的续费预览。该订阅在仪表盘显示「长期有效」，与商店的 365 天标题有出入。需要保存余额超过一年时，请按自己订单的有效期向客服核对。

商店另有明确标注「不限时」的来财和鸿运，券后分别为 ¥28.80/100GB 和 ¥79.20/300GB。三款季付或年付的特惠套餐当次也没有通过验券，商品名称只给出 200GB 或 400GB 和付款周期。因为重置时间待确认，计算这些套餐的月均可用额度前应先查清发放规则。[九云商品卡与验券截图](https://jichangceshi.com/posts/jiuyun)
