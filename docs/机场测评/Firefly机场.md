## Firefly 套餐价格与流量

| 套餐 | 页面标价 | 流量 |
| --- | ---: | ---: |
| Firefly Lite | ¥25/月 | 150GB/月 |
| Firefly Plus | ¥45/月 | 300GB/月 |
| Firefly Blaze | ¥85/月 | 600GB/月 |
| Firefly Nova | ¥150/月 | 1,000GB/月 |
| Firefly 年付版 | ¥96/年 | 60GB/月 |
| Firefly 不限时 | ¥100/次 | 总计 100GB |

如果每月用量接近 100GB，Lite 的 150GB 留有余量，年付版则会遇到每期 60GB 的上限。年付版折合 ¥8/月，但购买时需一次支付 ¥96。偶尔需要更多流量时，先看后台是否可以加购或提前重置，再计算年付和月付的实际差价。

不限时包适合跨月备用。按表内标价，¥100 相当于四个月 Lite 的费用。如果只需要集中使用一个月，Lite 的前期支出更低。服务商把不限时包描述为 100GB 用完为止，付款前可向客服确认用完如何续购，以及能否和现有套餐同时使用。
